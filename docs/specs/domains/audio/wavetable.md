# The Wavetable block

## Purpose
How the Wavetable source (`source.wavetable`, CHG-0029) makes sound, so it can be checked without a v1 reference.

## Requirements
- **R1.** Tables are generated by the engine from maths (no stored audio, DATA-0005), identically on every build and
  every sample rate; each frame peaks at 1 and has no DC.
- **R2.** A voice reads the band with the most harmonics that stays under Nyquist for its table frequency (note /
  period), faded toward the next band, so no harmonic above Nyquist is read and a glide never steps.
- **R3.** Reference oscillators: SYNC at Position 0 has the Tone saw's harmonic levels and PULSE at 0 the Tone
  square's (within 1 dB for the first nine harmonics), at the Tone's level (within 1.5 dB RMS).
- **R4.** Every table plays at the note: inharmonic tables put their partials at fixed ratios of it (BELL: prime at
  the note, minor-third tierce at 1.2 ×; CHIME: the bar's 2.76 ×, …). Note and Fine act as on the Tone.
- **R5.** Position (0–1) fades between neighbouring frames of 64; a change glides over about 5 ms and never
  re-pitches or retriggers a voice.
- **R6.** Output is independent of how the host cuts its buffers (as every source, SIMULATION-0001).
- **R7.** The options panel shows the frame being read, drawn by the same code (WASM `bd_table_picture`) at the
  Position slider's value, following an LFO that moves it.

## Verification
- `pnpm test:engine` (`test_wavetable_block.cpp`), golden fixtures `wavetable-bells` and `wavetable-sweep`
  (`pnpm bd render --check`, WASM, worklet and plugin agree), `pnpm test:new-blocks --only wavetable`.

## Notes
Table meanings (Position 0 → 1): BELL strike → hum; CHIME soft → hard mallet; GLASS rub → strike (pairs that beat);
GONG drum → gong; VOICE U-O-A-E-I; SWEEP a loud harmonic from the 2nd to the 32nd; SYNC saw synced 1 → 8 ×;
FOLD sine folded 1 → 10 ×; PULSE 50 % → 2 %.

# SCOPE-0004: Faithful v1 parity: same blocks, same look, same feel

## Decision
v2 ships the same 32 v1 blocks with the same geometry, palettes, interaction and sound character. No redesigns. Enhancements are limited to performance, determinism, tempo sync, the plugin, embeds and MCP. New blocks, such as new physics blocks, are additive and must pass the design library rules (UI-0003).

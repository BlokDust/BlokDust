# SCOPE-0002: Macros (grouped blocks)

## Context
Grouping blocks into a reusable macro with its own look needs design work: grouping and ungrouping, entering a macro, its visual identity, and its exposed params.

## Decision
Deferred until after v1 parity ships. The patch format reserves a top-level `macros` key so that adding it later is not a breaking change.

BlokDust {{VERSION}} for Windows
================================

BlokDust is a visual music playground: drop blocks, and nearby blocks connect.
This download installs:

  - BlokDust and BlokDust FX VST3 plug-ins, in C:\Program Files\Common Files\VST3
    (where Ableton Live, REAPER, Bitwig, Cubase and FL Studio look for them)
  - The BlokDust standalone app, in C:\Program Files\BlokDust

Install
-------

1. Unzip this folder.
2. Double-click BlokDust-{{VERSION}}-Windows.exe.
3. The installer isn't signed yet, so Windows may say "Windows protected your PC".
   If it does, choose More info, then Run anyway.
4. Rescan plug-ins in your DAW if BlokDust doesn't show up.

Needs Windows 10 (version 1809) or later, 64-bit, with Microsoft Edge WebView2
(built into Windows 11 and recent Windows 10).

Uninstall from Settings > Apps > Installed apps > BlokDust.
